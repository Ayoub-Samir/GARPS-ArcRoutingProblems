# Results Overview

This folder contains the performance evaluation of our proposed heuristic across multiple standard arc routing datasets. Each dataset is documented in a separate Word file (`.docx`), containing detailed comparison tables.

## Files

- `DRPP_Instances_Campos.docx`
- `MCPP_Instances_Corberan.docx`
- `MCPP_Instances_YaoyuenyongInstances.docx`
- `WRPP_Instances_Corberan.docx`

## Table Format (inside each .docx)

Each document includes a table structured as follows:

| Instance | Our Heuristic | Other Heuristic A | Relative Change % | Other Heuristic B | Relative Change % | ... |
|----------|----------------|-------------------|-------------------|-------------------|-------------------|-----|

### Explanation:

- **Instance**: The name or ID of the test case.
- **Our Heuristic**: The total cost of the solution generated by our approach.
- **Other Heuristic(s)**: Cost values from published heuristics for comparison. These may include:
  - Christofides's heuristic
  - Frederickson's heuristic
  - Yaoyuenyong's heuristic
  - Benavent's heuristic

## Notes

- All cost values are expressed in the same units (consistent with each dataset’s source).
- The emphasis of these tables is to **compare the trade-off between solution quality and time complexity**.
- For runtime details and complexity discussion, refer to the `ABSTRACT_and_Evaluation.docx`.
